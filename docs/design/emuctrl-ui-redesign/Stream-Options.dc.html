WHY FIVE
A 351px-tall rail holds five 52px keys with real 8px breathing room and still leaves the head and EXIT their own zones. Six fits only by dropping to 44px and killing the gaps — measurably worse under a moving thumb. So: KEYS · HOME · RECENT · SET in the arc, EXIT pinned bottom. SWAP left the rail because it's the most-used action and deserves the opposite thumb; HUD left because it's a glance, not a task — it hangs off the signal head. Anything new (screenshot, record, macros, clipboard) goes behind SET as a second tier, never as a sixth key.
